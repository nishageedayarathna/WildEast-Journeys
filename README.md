# WildEast-Journeys
Full-stack tourism website featuring dynamic destinations, travel articles and an admin dashboard.

## 🚀 Main Functionalities

### Public Website
- Interactive homepage showcasing travel experiences and destinations.
- Dynamic destination listings with images, descriptions, and highlights.
- Detailed destination information pages.
- Travel journal and blog article presentation.
- Tourist attraction management and display.
- Visitor reviews.
- Customer inquiry and contact functionality.
- Responsive user interface for different devices.

### Admin Dashboard
- Secure administrator login.
- Dashboard overview.
- Create, update, and manage travel destinations.
- Manage tour packages.
- Create and manage travel articles.
- View and manage customer inquiries.
- Manage tourist attractions.
- Manage visitor reviews.
- Update business and website settings.

### Database and Security
- PostgreSQL database integration.
- Supabase authentication.
- Administrator role management.
- Row Level Security (RLS).
- SQL database migrations.
- Dynamic database-driven website content.

## 🎯 Project Objective

To develop a dynamic and maintainable tourism management platform that provides travellers with accessible travel information while enabling administrators to efficiently manage destinations, tours, articles, and customer inquiries through a centralized dashboard.
